# Locksmith National (99-site network)

Standalone, templated pipeline that builds and deploys a national network of
locksmith websites to Cloudflare Pages. Each site is produced by token-replacing
a shared Astro template with per-location business data.

**This repo is fully self-contained** — it has no dependency on the multi-industry
content engine it was extracted from. Every script uses only Node built-ins.

## Layout

| Path | What |
|------|------|
| `data/locksmith-fleet/sites.csv` / `sites.json` | The 99-site fleet (business name, phone, address, logo, location, colour, CF project) |
| `data/locksmith-fleet/local-intelligence/` | Per-location intelligence used to enrich each site |
| `data/locksmith-fleet/enriched-cache/` | Cached enriched content per site |
| `data/locksmith-fleet/blocked.csv` | Sites excluded from deploy |
| `templates/locksmith-fleet/` | Canonical Astro template |
| `templates/locksmith-fleet-v2` … `-v4` | Template revisions |
| `scripts/locksmith-fleet/` | Build / enrich / deploy / IndexNow / GSC / regeneration scripts |
| `output/` | Per-site build output (git-ignored, regenerated by `redeploy.mjs`) |

## Build & deploy

The build/deploy orchestrator is `scripts/locksmith-fleet/redeploy.mjs`. For each
row in `data/locksmith-fleet/sites.json` it copies the template, replaces the
site tokens (`{{name}}`, `{{phone}}`, `{{address}}`, `{{logo_url}}`, `{{location}}`,
`{{color}}`), runs `astro build`, and deploys `dist/` with `wrangler pages deploy`.

```bash
# Substitute only, no build/deploy (proof of concept)
node scripts/locksmith-fleet/redeploy.mjs --domain <domain> --dry-run

# Build a single site but don't deploy
node scripts/locksmith-fleet/redeploy.mjs --domain <domain> --skip-deploy
```

See `scripts/locksmith-fleet/README.md` for the full script reference.

## Required env (for real deploys)

Copy `.env.example` to `.env` and fill in your Cloudflare credentials:

```
CLOUDFLARE_ACCOUNT_ID=...
# Option A — scoped token
CLOUDFLARE_API_TOKEN=...
# Option B — global API key
CLOUDFLARE_EMAIL=...
CLOUDFLARE_API_KEY=...
```
